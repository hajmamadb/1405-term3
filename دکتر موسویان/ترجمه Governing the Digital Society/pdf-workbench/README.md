# برگه — نسخه اجرای خودکار

## راه‌اندازی بدون دستور نصب
1. Python 3.10 یا جدیدتر باید روی دستگاه نصب باشد (در ویندوز گزینه Add Python to PATH).
2. ویندوز: روی `start.bat` دوبار کلیک کنید. سایر سیستم‌ها: `python3 start.py`.
3. اجراکننده محیط مستقل `.runtime` را می‌سازد، وابستگی‌ها را خودکار نصب می‌کند، سرور پورت 4356 را اجرا و مرورگر را باز می‌کند. پنجره اجرا باز بماند.

اولین نصب نیازمند اینترنت و اجازه نوشتن در پوشه برنامه است. جزئیات نصب در `setup.log` ثبت می‌شود. موفقیت نصب روی همه سیستم‌ها تضمین‌شده نیست؛ در صورت اشکال اتصال اینترنت و این فایل را بررسی کنید.

HTML را با دوبار کلیک جداگانه باز نکنید؛ ورودی برنامه start.bat است. مرورگر عادی مجوز نصب وابستگی یا روشن کردن پردازش محلی خاموش را ندارد. نصب و راه‌اندازی قبل از بازشدن رابط انجام می‌شود، نه با JavaScript مرورگر. برای برنامه کاملاً مستقل از Python، باید نسخه اجرایی متناسب با سیستم‌عامل بسته‌بندی شود؛ این بسته سورس Python است.

## تنظیمات
آدرس، مدل و کلید اعلام‌شده کاربر در اولین اجرا به جدول settings دیتابیس اضافه می‌شوند. رابط مقادیر را از دیتابیس می‌خواند.
- «ذخیره تنظیمات»: ثبت در SQLite؛ نه localStorage.
- «ذخیره و بررسی سرویس»: ذخیره در دیتابیس و درخواست به `<base_url>/models` برای بررسی ارتباط. عدم پشتیبانی ارائه‌دهنده از /models لزوماً به معنی خرابی ترجمه نیست.
- شروع/ادامه: ذخیره تنظیمات و شروع پردازش. درخواست ترجمه به `<base_url>/chat/completions` است.
- سازگاری آدرس https://ai.ismc.ir/api با این مسیرها در سرویس واقعی تست نشده است.

کلید در SQLite و مقدار اولیه کد به‌صورت متن ساده نگهداری می‌شود؛ برای استفاده محلی شخصی طراحی شده است. برنامه فاقد احراز هویت است؛ روی اینترنت منتشر نشود. فایل‌ها و دیتابیس را عمومی نکنید.

## خروجی
در `data/<project-id>`: PDF اصلی، تصویر PNG، متن انگلیسی و فارسی و Word مستقل هر صفحه ذخیره می‌شود. ثبت done فقط پس از ذخیره خروجی‌های همان صفحه انجام می‌شود. صفحات تکمیل‌شده تکرار نمی‌شوند؛ قطع وسط صفحه ممکن است همان صفحه ناتمام را تکرار کند. پس از اجرای مجدد «شروع / ادامه» را بزنید.

## رفتار در برابر خطا (شروع نسخه ۲)
اگر صفحه‌ای خطا بدهد (مثلاً متن قابل استخراج ندارد یا مدل خطا می‌دهد)، آن صفحه **ردشده** علامت‌گذاری می‌شود و پردازش به صفحه‌های بعدی **ادامه می‌یابد**؛ خطای یک صفحه دیگر کل پروژه را متوقف نمی‌کند. وضعیت نهایی پروژه «تکمیل‌شده» است و صفحات خطادار در فهرست صفحات قرمز و با پیام خطا نمایش داده می‌شوند.
- دکمه «تلاش مجدد برای صفحات خطادار» صفحات ردشده را دوباره در صف می‌گذارد تا پس از رفع علت (مثلاً OCR برای صفحه اسکن‌شده) دوباره پردازش شوند.
### صفحات خالی / بدون متن (اسکن‌شده)
صفحه‌ای که متن قابل استخراج ندارد (صفحهٔ خالی، جلد، یا صفحهٔ اسکن‌شده بدون لایهٔ متن) **خطا محسوب نمی‌شود**:
- اسکرین‌شات (تصویر PNG) آن صفحه **گرفته می‌شود** و قابل مشاهده/دانلود است.
- صفحه به‌عنوان **تکمیل‌شده** ثبت می‌شود (نه ردشده) و error نشان داده نمی‌شود.
- در فایل‌های دانلودی، یک جملهٔ ثابت درج می‌شود: برای بخش انگلیسی **Not Found** و برای بخش فارسی **فاقد متن** — یعنی شماره‌بندی صفحات با سند اصلی مطابقت دارد و جای خالی نمی‌ماند.
- (برای ترجمهٔ واقعی این صفحات، ابتدا باید OCR روی PDF انجام شود؛ خروجی OCR را جایگزین PDF کنید و دوباره پردازش کنید.)

فقط صفحات «در انتظار» و «در حال پردازش» در ادامه پردازش می‌شوند؛ صفحات ردشده تا زمانی که «تلاش مجدد» نزنید تکرار نمی‌شوند تا worker روی صفحهٔ خراب گیر نکند.
- اگر کل پروژه خطای اساسی بگیرد (مثلاً PDF مفقود یا مشکل دیتابیس)، وضعیت «خطا» روی خود پروژه ثبت می‌شود؛ این با خطای صفحه‌ای متفاوت است.

Word تجمیعی از رابط قابل دریافت است. تصویر، انگلیسی و فارسی هرکدام از صفحه جدید آغاز می‌شوند؛ متن بلند ممکن است بیش از یک صفحه شود. PDF اسکن‌شده/صفحه بدون متن به OCR نیاز دارد. استخراج جدول و چیدمان پیچیده ممکن است دقیق نباشد؛ ترجمه ماشینی باید بازبینی شود.

فقط یک نمونه برنامه و یک worker اجرا شود. تست مستقل از مدل: `python test_app.py` پس از نصب وابستگی‌ها یا با Python محیط `.runtime`.

## بازبینی کیفیت ترجمه
پس از اتمام ترجمه، دکمهٔ «بازبینی و اصلاح کیفیت ترجمه» برای هر صفحهٔ تکمیل‌شده، متن انگلیسی و متن فارسی را با هم به مدل می‌دهد تا ترجمهٔ فارسی را **اصلاح** کند (فیدلیتی به متن اصلی، رفع خطا/حذف/اضافه‌شدن، گرامر و املای فارسی). این مرحله:
- **صفحه‌به‌صفحه** اجرا می‌شود و قابل توقف/ادامه است؛ اگر صفحه‌ای خطا بدهد «ردشده» علامت می‌خورد و بقیه ادامه می‌یابد.
- **قابل اجرا هم‌زمان با ترجمه:** بازبینی در تسک مستقلی می‌چرخد و فقط صفحات تکمیل‌شده را می‌خواند، بنابراین می‌توانید وسط ترجمه، بازبینی را هم شروع کنید؛ صفحاتی که تازه ترجمه می‌شوند، به‌محض تکمیل، بازبینی می‌شوند.
- **موازی (تعداد موازی):** از انتخابگر «تعداد موازی بازبینی» مشخص کنید چند صفحه هم‌زمان به مدل فرستاده شود (۱ = ترتیبی، تا ۴ = سریع‌تر). هرچه بیشتر، بازبینی سریع‌تر اما بار بیشتری روی سرویس می‌اندازد.
- مدل بازبینی را از فهرست انتخاب کنید (می‌تواند **همان مدل ترجمه یا مدل دیگری** باشد)؛ فقط مدل‌های **چت/تولید متن** قابل استفاده‌اند (نه embedding یا ASR). پیش‌فرض: `qwen38-nothinking`؛ گزینه‌های دیگر: `qwen38` و `qwen38-sglang`.
- خروجی اصلاح‌شده در `data/<project-id>/page-NNNN.fa.review.txt` و دیتابیس (جدول reviews) ذخیره می‌شود و با «دانلود ترجمه فارسی (بازبینی‌شده)» قابل دریافت است.
- هر صفحه برای بازبینی یک درخواست کامل به مدل می‌فرستد؛ بنابراین **هر صفحه ممکن است چندین ثانیه طول بکشد** (بسته به مدل و طول صفحه). برای ۲۶۵ صفحه، زمان قابل‌توجهی لازم است؛ می‌توانید چند صفحه را بازبینی کرده، کیفیت را ببینید و سپس ادامه دهید.

## نصب (فایل نصبی تک‌فایلی، کاملاً آفلاین)
برای توزیع یا نصب روی سیستم دیگر بدون نیاز به Python یا اینترنت:

1. در این پوشه، فایل نصبی را بسازید (یک‌بار، روی همین سیستم):
   ```
   python build_installer.py
   ```
   خروجی: `dist/Baraghe-Setup.bat` (حدود ۵۰ مگابایت؛ کل برنامه + زمان‌بندی‌شدهٔ Python + همهٔ وابستگی‌ها + فونت‌های محلی).
2. فایل `Baraghe-Setup.bat` را به سیستم مقصد منتقل و اجرا کنید.
3. مسیر نصب را بپذیرید (پیش‌فرض `%LOCALAPPDATA%\Baraghe`) یا مسیر دلخواه بدهید.
4. نصب‌کننده فایل‌ها را باز می‌کند، یک میان‌بُر دسکتاپ «Baraghe» می‌سازد و برنامه را راه‌اندازی می‌کند (مرورگر به‌طور خودکار باز می‌شود).

- **کاملاً آفلاین:** زمان‌بندی‌شدهٔ Python و تمام وابستگی‌ها داخل فایل نصبی است؛ در سیستم مقصد نیازی به Python یا اینترنت نیست.
- **داده‌های کاربری همراه نصب نمی‌رود:** پوشهٔ `data/` (پروژه‌ها و ترجمه‌ها) در فایل نصبی وجود ندارد؛ نصب تازه از صفر شروع می‌شود.
- **اجرا/توقف:** برای اجرای مجدد، از میان‌بُر دسکتاپ استفاده کنید؛ برای توقف سرور، پروسهٔ `pythonw.exe` را در Task Manager ببندید (یا پنجرهٔ کنسول مربوطه را).
- ساختار نصب: `<install>\app.py`، `<install>\static\`، `<install>\python-runtime\` (زمان‌بندی‌شدهٔ Python) و `<install>\data\` (که هنگام اولین اجرای ترجمه ساخته می‌شود).

### ساختار پروژه
- `app.py` — سرور FastAPI (استخراج، ترجمه، بازبینی، دانلودها، آپلود، تنظیمات).
- `static/index.html` — رابط کاربری تک‌فایلی (RTL، فونت محلی وزیر، نوار پیشرفت، مودال مشاهدهٔ متن).
- `static/fonts/vazirmatn-var.woff2` — فونت وزیر (متغیر) برای نمایش بدون اینترنت.
- `start.py` / `start.bat` — راه‌انداز (در حالت نصب‌شده از `python-runtime` استفاده می‌کند؛ در حالت سورس، venv می‌سازد).
- `build_installer.py` — سازندهٔ فایل نصبی تک‌فایلی.
- `test_app.py` — تست‌های خودکار.
- `requirements.txt` — وابستگی‌ها (فقط برای حالت سورس؛ در نسخهٔ نصب‌شده پیش‌نصب‌اند).
